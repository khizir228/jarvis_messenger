# Jarvis Messenger 4.1

## Запуск

1. Запусти `START_JARVIS.bat`.
2. Открой `http://127.0.0.1:8000`.
3. Для устройств в той же Wi-Fi сети открой `http://IP_компьютера:8000`.

## Если порт 8000 занят

```bat
netstat -ano | findstr :8000
taskkill /PID НОМЕР_PID /F
```

## Важно

- Не запускай одновременно две копии сервера на 8000.
- База `app/messenger.db` создаётся автоматически.
- Русский текст сохранён в UTF-8.
- WebSocket использует текущий адрес страницы, поэтому работает и через LAN.
